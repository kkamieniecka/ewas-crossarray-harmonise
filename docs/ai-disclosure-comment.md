**Disclosure of AI assistance**

Parts of this package were written with the help of an AI coding assistant, and
per the Bioconductor policy on AI-generated and third-party code I want to say
exactly where, and what I did about it.

**What was assisted.** The numerical core — everything in `R/` apart from
`R/classes.R` — is generated by a script from a single source file,
`bin/ewasml.R`, in the pipeline repository
[kkamieniecka/ewas-crossarray-harmonise](https://github.com/kkamieniecka/ewas-crossarray-harmonise).
That source file, its Python twin `bin/ewasml.py`, the generator
`tools/build_pkg.py`, the test suites and the vignette were drafted in assisted
sessions in September 2026, working from method descriptions and design
decisions I gave. I reviewed and edited the result function by function. The
commits from those sessions are attributed as such in the pipeline repository's
history rather than presented as mine [AUTHOR: confirm you are happy to point
reviewers at that history; commits before `ee0d848` carry the assistant's
authorship, later ones carry mine].

**Provenance.** No code was copied from another package or repository. The
methods are implemented from their published descriptions, not adapted from
existing implementations: subject-level stability selection after Meinshausen
and Bühlmann; total-variation denoising with a distance-dependent penalty;
a hidden semi-Markov model for block state; and region and block conventions
that follow `bumphunter` and `minfi::blockFinder` in intent while being
independently written [AUTHOR: add the citations you want named here — they
should match the manuscript's reference list].

**Licence.** All of it is original to this project and released under the
package's MIT licence. Nothing with incompatible terms is vendored.

**Responsibility and independent validation.** I am responsible for the
correctness and the maintenance of this code. It has not been taken on trust
from the tool that drafted it:

- The core exists as two independent implementations, in R and in Python, and a
  cross-language test asserts they agree function by function on shared
  fixtures — 55 checks, all passing, run in CI on every push.
- The package's R sources are generated from that core and a test
  (`tests/test_pkg_identity.R`, 27 checks) asserts the function bodies are
  byte-identical to it, so the package cannot silently drift from the version
  the equivalence test covers.
- 180 `testthat` expectations in 55 blocks cover the exported surface directly.
- The pipeline has been run end to end on a real longitudinal cohort
  (GSE237561), and the two new region and block callers were compared against
  `bumphunter` and `blockFinder` on the same harmonised data; that comparison
  is the subject of a manuscript in preparation and the outputs are in the
  pipeline repository under `results/GSE237561/`.
